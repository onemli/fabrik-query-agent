edmNicProf

External Device Manager NIC Profile · edm:NicProf

External Switch Controller Profile specifies how to connect to a single External Switch Management Controller that is part of containing policy enforcement domain. For example, policy to connect a Cisco UCSM that is part a External Device Manager Group.
