# Fabrik Query Agent: APIC object model

Every class of Cisco ACI's management information model (APIC 6.1.1), one page each: what it holds, its DN, its
properties and their values, and moquery and REST queries that read it. Cloud APIC, hidden, deprecated and
statistics classes are left out.
