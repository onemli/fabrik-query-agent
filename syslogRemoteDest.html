Syslog Remote Destination · syslog:RemoteDest

The syslog remote destination host enables you to specify syslog servers to which messages from the APIC and fabric nodes should be forwarded.

moquery namesyslog.RemoteDest
Kindconfiguration (written on APIC)
Layerambiguous

Queries

APIC stands for the APIC's address. Read only. A few classes cannot be asked fabric-wide: APIC then answers Unable to resolve destination node; ask one switch instead, /api/class/topology/pod-1/node-101/CLASS.json, or the DN of an object above it.

moquery -c syslogRemoteDest
moquery -c syslogRemoteDest -f 'syslog.RemoteDest.adminState=="disabled"'
