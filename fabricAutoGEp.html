fabricAutoGEp

VPC Auto Protection Group · fabric:AutoGEp

A VPC auto-protection group. This represents a VPC domain (a protection group). You can set the type of algorithm to be used for creating the automatic groups. Based on the algorithm, APIC implicitly makes discovered nodes part of the group.
