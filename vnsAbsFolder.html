vnsAbsFolder

L4-L7 Services Folder · vns:AbsFolder

A folder added to an abstract graph. An abstract graph folder can contain an abstract graph folder (AbsFolder) and abstract node parameters (AbsParam), which are analogous to an MFolder and MParam. An abstract graph folder can be contained under abstract device configuration (AbsDevCfg), abstract group configuration (AbsGrpCfg), or abstract function configuration (AbsFuncCfg).
